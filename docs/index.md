# QAP documentation

QAP has two parts, the middleware and the client, and each is documented as a plan: one page per name in the code, from what a person does down to the atomic parts, each with its own code. The flow puts the pages of both plans in the order they take part, from the first request to the audit trail. Start at the top of a plan, or follow the flow.
