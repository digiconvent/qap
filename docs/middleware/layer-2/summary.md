# Layer 2: the intents

Layer 2 holds the intents: the seven things a client can ask a QAP endpoint, chosen with the `X-QAP-Intent` header. Each page says what the intent does, which headers it needs, what it returns and which errors it can give. They are listed in the order they are usually used.
