# C2 Author

The author is the person who created a [submission](submission.md) with [Submit](../layer-2/submit.md). Their submission counts as their own vote in favour. Only the author can [Withdraw](../layer-2/withdraw.md) the submission, and only the author sees the data of a [Sensitive read](sensitive-read.md).

---

**Kind:** concept.

The user id that the [Current user](../host/current-user.md) gave when the submission was created. [Authorship](../layer-4/authorship.md) compares it with the user of a later request.
