# Flow

This is the whole life of a submission, from the moment the host starts QAP to the moment a decided submission is cleaned up, in chronological order. Each row is one step; each column is a layer, and names the pages that take part in that step by their code. The columns run from the person, through the client, to the server and the host behind it.
