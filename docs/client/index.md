# QAP client plan

Every name below has its own page and its own code: `c` for the client, a letter for the layer, and a number for the place in the summary of that layer. Each page describes its name in a few sentences, followed by technical details below a horizontal line, and a list of the pages that refer to it. Each heading below links to a summary of that layer. The [flow](../flow.md) shows in which order the pages take part, from the person to the server and back. Start at the top and follow the links down.
