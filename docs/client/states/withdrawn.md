# cS6 Withdrawn

The answer to a successful [Withdraw](../layer-2/withdraw.md). Only the id remains; the submission is gone from the server. It has no moves: go back to the [Endpoint](../layer-1/endpoint.md).

**Kind:** state, `kind: 'withdrawn'`.
